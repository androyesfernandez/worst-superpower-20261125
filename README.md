# Worst Superpower

A one-line program for the "Worst Superpower" competition: it writes the single most useless superpower ever — remembering every password you have ever forgotten, but only the second after you clicked reset, and only for accounts that no longer exist. Run `main.ts` with Node 22 and it produces `/output/entry.txt`, exactly 139 characters with no trailing newline.
